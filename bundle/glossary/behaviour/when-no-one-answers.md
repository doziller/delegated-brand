# Instructions

Replace this section. Keep the headings below.

A permission often covers several actions that are very different services. When nobody decides, the default decides, usually in favour of whatever is quickest or earns most. Write the default down before a system writes it for you.

- Under "Agent may decide", name the room an agent has inside this rule, for example "which element gets the accent". Leave it empty if there is none.
- In "Defaults", list 10 to 20 actions an agent or system takes for customers or partners. For each, write what happens today when no one answers, what is legally allowed, what the brand claims, and the default you decide.
- Expect inconsistencies: some actions wait, others run, and nobody intended the difference.
- Write each default as a rule a system can follow, not as tone. For example: "If no answer arrives, nothing is executed."
- In "Always carried", list the information that goes with every transaction, even when nobody asks and even when another system rewords the message. Tone does not survive rewording. Structure does.
- In "Declined, even when allowed", list what the brand does not do although a permission would cover it. Restraint costs something, and that is why it is believable.
