# Preference

Daylight, real kitchens, real roasteries, hands on the crank. A grinder with some wear is better than one fresh from the box. Weigh this against the job: a spare-parts catalogue needs plain cut-outs, and that is fine.

# Why

"Made to be passed on" is easier to believe when the photo shows a grinder that has already been used for years.

This is a preference, not a limit. An agent weighs it and says when it chose otherwise.
