# When

One element per surface: the action we want people to take, or the one fact they need. A "Book a wheel class" button. The opening hours on a closed-door sign.[^kiln-brand-book]

# When not

- Never as a full-page background. Clay on large areas reads as a warning.
- Never for decoration. If nothing needs attention, nothing is Clay.
- Never for error states. Errors have their own token in the design system.

# Why

Kiln's interiors are muted so that the ceramics carry the colour. Clay copies the colour of fired earthenware, so it reads as "ours". It only works if it stays rare.

# Rejected

- **Clay for every button.** Tried on the first website in 2025. With four Clay buttons on one page, none of them stood out. Dropped in favour of one per surface.
- **A second accent in sage green.** Considered for the café menu. Dropped because it split attention between studio and café, which Kiln wants to feel like one place.
